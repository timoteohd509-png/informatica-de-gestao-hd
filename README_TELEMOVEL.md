# Informática de Gestão HD — Pacote para Telemóvel

Publicador: Timóteo HD
Application ID: ao.timoteohd.informaticagestaohd

## Caminho recomendado
1. Coloque este projecto num repositório GitHub.
2. No GitHub, abra **Actions** e execute o workflow `Build Android AAB`.
3. O workflow gera um AAB de release.
4. Para uma versão assinada, configure os segredos de assinatura no GitHub conforme `docs/ASSINATURA.md`.
5. Nunca envie a sua palavra-passe ou ficheiro de chave para outra pessoa.

## Importante
O nome "Timóteo HD" é o nome de publicação/apresentação. A assinatura Android é uma chave criptográfica que deve ficar sob o controlo do proprietário.
